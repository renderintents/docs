---
title: "Flag"
description: "Flags someone as a cheater manually without needing 'Anti Cheat' module"
---

<Tip>
  This will make combat modules prioritize that Player over other Legit Players
</Tip>

<Tip>
  They also get a funni 'SKID' chat tag when flagged
</Tip>

## Syntax

| Component  | Description                      | Example | Type   | Optional
| :--------- | :------------------------------- | :------ | :----- | :-----
| **Match** | The player's name                 | `skid6769` | string | false

\*\*Final Example: \*\*`.flag skid6769`
