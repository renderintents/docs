---
title: "Teleport"
description: "Teleports You to a Position in the World"
---

| Component  | Description                      | Example | Type   | Optional
| :--------- | :------------------------------- | :------ | :----- | :-----
| **X** | The X Coordinate       | `1`| number | false
| **Y**   | The Y Coordinate         | `1` | number | true
| **Z**   | The Z Coordinate         | `1` | number | true

<b> Final Example: </b>`.teleport 1 1 1`
