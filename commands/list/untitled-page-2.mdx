---
title: "Unbind"
description: "Removes a key bind from a Module"
---

<Tip>
  No arguments are case sensitive. If you don't know the name of your key you could retrieve [here](https://create.roblox.com/docs/reference/engine/enums/KeyCode)
</Tip>

## Syntax

| Component  | Description                      | Example | Type   | Optional
| :--------- | :------------------------------- | :------ | :----- | :-----
| **Module** | The module to unbind      | `Fly`| string | false

<b> Final Example: </b>`.unbind Fly`
