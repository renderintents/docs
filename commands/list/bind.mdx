---
title: "Bind"
description: "This command is a core utility that allows you to link a specific Packet module to a physical key. This eliminates the need to open the Click GUI during the gameplay."
---

<Warning>
  **Keyboard Required**: This command is intended for devices with physical keyboards. If you are on a mobile device or console without a keyboard, you should skip this section and use the Click GUI instead.
</Warning>

<Tip>
  The Key is NOT case sensitive. If you don't know the name of your key you could retrieve [here](https://create.roblox.com/docs/reference/engine/enums/KeyCode)
</Tip>

## Syntax

| Component  | Description                      | Example | Type   |
| :--------- | :------------------------------- | :------ | :----- |
| **Module** | The module to bind               | `Fly`   | string |
| **Key**    | The key to to bind to the Module | `R`     | string |

\*\*Final Example: \*\*`.bind Fly R`
