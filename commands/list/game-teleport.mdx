---
title: "GameTeleport"
description: "Teleports you to another game via Place ID"
---

## Syntax

| Component  | Description                      | Example | Type   | Optional
| :--------- | :------------------------------- | :------ | :----- | :-----
| **Place ID** | The Place ID of the game       | `189707`| number | false
| **Job ID**   | The Job ID of the game         | `8791f` | string | true

<b> Final Example: </b>`.gameteleport 189707 8791fb01-59e5-4965-9cf8-9e218f84a775`
