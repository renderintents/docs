---
title: "Goto"
description: "Teleports you to a specified Entity"
---

<Tip>
  This works on any entity registered in Packet, therefore you could teleport to NPCs too!
</Tip>

<Tip>
  You don't need to type out the entity's full name nor is it case sensitive. Providing no match teleports you to a random entity 
</Tip>

| Component  | Description                      | Example | Type   | Optional
| :--------- | :------------------------------- | :------ | :----- | :-----
| **Match** | The entity's name                 | `blank` | string | true
| **Time**  | Time to travel (instant )         | `8791f` | number | true
